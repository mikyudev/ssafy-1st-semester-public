# SSAFY 1st Semester Public Study

공개해도 괜찮은 개인 풀이 코드만 모은 저장소입니다.

## Structure

```text
algorithms/
  boj/        # 백준 풀이
  swea/       # SWEA 풀이
  review/     # 복습 코드
  im/         # IM 유형 풀이 코드
  a-type/     # A형 유형 풀이 코드
  daily-practice/  # 날짜별 알고리즘 풀이와 입출력 txt
  sw-advanced/     # 알고리즘 심화 풀이와 입출력 txt
```

## Public Rule

이 저장소에는 아래 자료를 넣지 않습니다.

- SSAFY 시험/평가 문제 원문
- 수업 PDF, DOCX, PPTX, XLSX
- Django `db.sqlite3`, `venv`, `.env`
- 강의/시험 대비 메모가 포함된 파일

알고리즘 풀이 옆의 작은 `txt` 파일은 입출력 확인용으로 함께 보관합니다.

민감하거나 애매한 자료는 private 저장소로 분리합니다.
